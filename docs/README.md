# Documentation Administrateur - Médiathèque TLN

Cette documentation est hébergée sur GitHub Pages.

**Accès :** [Voir la documentation](./index.html)

## Structure

- `index.html` : Page principale de documentation
- `style.css` : Feuille de style

## Activation de GitHub Pages

1. Allez dans les paramètres du repository
2. Section "Pages"
3. Source : Branche `create-documentation`, dossier `/docs`
4. Enregistrez

Votre documentation sera accessible à l'URL :
`https://[votre-username].github.io/mediatheque-tln-grp3/`
